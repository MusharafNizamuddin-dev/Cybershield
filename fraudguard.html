Accepted Transaction Log Format

FraudGuard analyzes synthetic transaction logs in CSV or JSON format. Use the required fields below so the detection engine can evaluate transaction behavior.

01 · Supported files

.CSV.JSON

CSV is recommended for quick testing. JSON may contain an array directly or an object with a transactions array.

02 · Required fields

timestamp10:30:12
transaction_idTX1001
user_idU42
amount2499
countryIN
device_idD102
statusapproved / declined

03 · CSV example

timestamp,transaction_id,user_id,amount,country,device_id,status
10:30:12,TX1001,U42,499,IN,D102,approved
10:31:04,TX1002,U42,799,IN,D102,declined
10:31:18,TX1003,U42,899,US,D991,declined
10:31:27,TX1004,U42,1299,US,D991,declined

  "transactions": [
    {"timestamp":"10:30:12","transaction_id":"TX1001","user_id":"U42","amount":499,"country":"IN","device_id":"D102","status":"approved"}
  ]
}

05 · Safety & privacy

Never upload real payment information. Do not include card numbers, CVVs, PINs, passwords, bank credentials, or other sensitive financial data. Use synthetic/test records only.
