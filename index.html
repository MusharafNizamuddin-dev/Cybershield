Website Protection

Connect your website

Works with any site that uses Cloudflare (WordPress, PHP, Python, static sites and more). Nothing to install on your server.

How do I get a token?
  1. Open the Cloudflare dashboard, then My Profile > API Tokens.
  2. Choose Create Token > Create Custom Token.
  3. Add these permissions: Zone > Zone > Read, Zone > Zone WAF > Edit, and Zone > Analytics > Read (for the counters).
  4. Under Zone Resources pick Include > Specific zone and choose your site.
  5. Create the token and paste it here.

Your token is stored encrypted and only used to add or remove one rate-limit rule. You can revoke it in Cloudflare at any time.

Which file is my main file?
  1. Open the file called package.json in your website's files.
  2. Find the word "start". Next to it you will see something like node server.js.
  3. The name after node (here server.js) is your main file. If you don't see it, look for "main" in the same file.
  4. On GitHub: open that file, tap the pencil icon, paste on the first line, then tap Commit changes.

Step 3. Restart your website. Hosts like Render and Railway restart by themselves after you save the file on GitHub. Otherwise tap Restart or Deploy on your host. This page turns green when your site connects. Nothing is blocked until you switch rate limiting on.

If your code is on a public page (like public GitHub), anyone could read the key inside this code. In that case set the key as a secret named CYBERSHIELD_KEY on your host instead.
